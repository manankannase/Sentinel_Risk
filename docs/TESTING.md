# Testing guide

## First run

From the project directory:

    uv sync --frozen
    uv run python scripts/bootstrap.py
    uv run python -m sentinel.db migrate
    uv run uvicorn sentinel.api:app --host 127.0.0.1 --port 8000 --no-server-header

Open http://127.0.0.1:8000. For **Workspace key**, paste the full line from `.secrets/admin_token`. It is generated by bootstrap. It is not a student ID or external account key.

On macOS:

    pbcopy < .secrets/admin_token

## Functional test

Keep the server running. In a second terminal:

    uv run python scripts/replay.py --count 80 --feedback

The dashboard should show scored transactions, decision counts, amount volume, model details, feedback labels, and system health. Use the Score page to submit one transaction manually; the browser generates the transaction ID and timestamp.

## Automated verification

    uv run ruff check .
    uv run pytest -q
    uv run pip-audit

Tests cover strict input boundaries, authorization roles, tenant isolation, idempotency, immutable feedback, event ordering, history leakage, body limits, model integrity, and feature order.

## Container test

    uv run python scripts/bootstrap.py
    docker compose config --quiet
    docker compose up --build -d
    docker compose ps
    curl --fail http://127.0.0.1:8000/readyz

Run bootstrap only once. If `.env` and `.secrets` already exist, preserve them. Use `docker-compose` where Docker Compose is installed as a standalone command.

Stop containers without deleting data:

    docker compose down

Do not add `-v` unless you intentionally want to delete local PostgreSQL and Redis volumes.

Optional monitoring test:

    docker compose -f compose.yaml -f compose.observability.yaml --profile observability up -d
    curl --fail http://127.0.0.1:9090/-/ready
    curl --fail http://127.0.0.1:3000/api/health

Open Prometheus at http://127.0.0.1:9090 and Grafana at http://127.0.0.1:3000. Grafana username is `admin`; use `GF_ADMIN_PASSWORD` from `.env`.

## Retrain intentionally

Write a new immutable model directory, review metrics, then promote its three serving files (`model.json`, `manifest.json`, `metrics.json`) into `artifacts/`. After promotion:

    uv run python scripts/sync_model_digest.py

This updates only the pinned model digest. It does not rotate workspace or database credentials.
